# Reference look photos (M5 onboarding swipe cards)

**Not used today:** the cards show drawn illustrations (`looks_svg.py`, `art` in `reference_looks.json`).
This folder is for a later photo series. The 4 previews below are 161×200 AI previews, kept as a start.

One photo per style, generated by AI (Canva "generate image"), portrait 4:5. Save each as `<id>.png` in this
folder and set, in `reference_looks.json`:

```json
"image_url": "/m05/ui/looks/photos/<id>.png", "vector_source": "image"
```

M5 then shows the photo on the card and embeds it with FashionCLIP (through M1). A look without a photo keeps
its SVG placeholder and the vector of its description. Check the result with
`python -m modules.m05_style_profile.scripts.check_look_photos` (real mode: each photo should land on its style).

Every prompt uses the same frame, so the 12 cards look like one series:

> Full-body fashion catalogue photograph of a young woman wearing **{outfit}**. Standing straight, facing the
> camera, whole outfit visible from head to shoes. Plain light warm grey studio background, soft even
> lighting, realistic photography, no text, no logo.
